# Growth Journal 실습 · 표준 하네스

Copilot Studio **표준 하네스**로 개인용 성장 기록 Teams 에이전트(Growth Journal)를 만드는 단계별 실습 사이트입니다.

"시작했어", "메모", "끝났어"만 말하면 Planner와 SharePoint에 기록이 쌓이고, 연말에 근거가 붙은 돌아보기를 받는 에이전트를 직접 만듭니다.

- 사이트: https://dongkyuseoossdata.github.io/growth-journal-lab-standard/
- 다음 단계: 같은 에이전트를 GitHub Copilot 하네스로 만드는 [GHCP 실습](https://dongkyuseoossdata.github.io/growth-journal-lab-ghcp/)

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 실습 사이트 본문 (M0~M12, 체크리스트, 복사 버튼) |
| `img/` | 실습 스크린샷 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 서비스하게 함 |

## 권장 순서

두 실습은 각각 따로 따라 할 수 있습니다. 표준 실습을 먼저 하면 GHCP에서 무엇이 줄어드는지 비교하며 볼 수 있어 더 좋습니다.

체크 상태는 각자의 브라우저(localStorage)에만 저장됩니다.
